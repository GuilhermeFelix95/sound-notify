# sound-notify

Sound notifications for [Claude Code](https://claude.com/claude-code).

- **Done:** a short rising chime when Claude finishes a turn.
- **Question:** a different rising glide when Claude asks you a question in **plan mode**.

Outside plan mode, every turn ends with the "done" sound, even if Claude ends with a question. Plan mode always plays a sound.

## Configuration

Create `~/.claude/sound-notify.json` (on Windows, in your user folder under `.claude`):

```json
{ "mode": "always" }
```

| mode | When the sound plays |
| --- | --- |
| `always` (default) | After every response. |
| `code-changes` | Only after a turn that edited files. Plan mode still always plays. |

A missing or invalid file uses `always`. Start a new session after changing the file.

## Requirements

- Claude Code with plugin support.
- Node.js 20 or later (used to run the hook).
- An audio player on your system:
  - Windows: built-in (PowerShell).
  - macOS: built-in (`afplay`).
  - Linux: `paplay` (PulseAudio/PipeWire) or `aplay` (ALSA).

## Installation

Works in the Claude Code CLI and the desktop app (they share the same configuration). Run these in a Claude Code session:

```
/plugin marketplace add GuilhermeFelix95/sound-notify
/plugin install sound-notify@sound-notify-marketplace
```

To install from a local clone (for development), add the folder as the marketplace instead:

```
/plugin marketplace add /path/to/sound-notify
/plugin install sound-notify@sound-notify-marketplace
```

Start a new session after installing so the hook is loaded.

## How it works

The plugin registers a `Stop` hook. When it runs, it reads the hook input from Claude Code and:

1. Uses the default "done" sound unless the session is in plan mode.
2. In plan mode, plays the "question" sound when the last assistant message used the `AskUserQuestion` tool or ends with `?`.

Sounds are generated by code, so the plugin ships no third-party audio.

## Development

```bash
npm test           # run the unit tests
npm run sounds     # regenerate sounds/*.wav
```

## Troubleshooting

- **No sound:** check that Node.js is on your `PATH`, and that your system has an audio player (see Requirements). Errors are printed to stderr as `sound-notify: ...`.
- The plugin never blocks Claude: it always exits with status 0.
